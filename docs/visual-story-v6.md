# 叙事与视觉重构（2026-09-26）

## 从哪里借鉴

- Apple 材质指南：https://developer.apple.com/design/human-interface-guidelines/materials
  借鉴内容与浮层的区分、轻量空间层次；不将正文都做成透明玻璃。
- Stripe Payments：https://stripe.com/payments
  已浏览实际页面；借鉴大标题 + 独立产品界面、按能力展开的章节叙事。未复制品牌内容或其业务指标。
- Linear Features：https://linear.app/features
  参考产品能力分组，不借用其深色调覆盖本项目的轻浅风格。
- 用户提供的扁平插画 UI 拼图：借鉴白色圆角界面与独立彩色内容。不是素材授权来源，没有复制图中图片或水印。

## 本次取舍

- Apple 风格技能提供基础层级参考（DESIGN.md）；用户要求优先，因此保留社区红、外卖蓝、浅紫辅助色和大圆角，而非机械照搬单一蓝色。
- 移除原紫色横向快捷入口与侧栏式痛点说明。改成：问题首屏 → 三个横向痛点 → 对应连接方案/必要性 → 完整可操作 Demo → 会话机制/验证边界。
- 浮动卡片引用已有原创布丁写实/像素图，保持比例，不复制第三方截图。两个卡片都可点击进入真实原型路径。
- 动效：卡片轻浮动、连接点单向移动、章节进入；导航提供动效开关，尊重 prefers-reduced-motion，键盘聚焦时停止卡片浮动。未引入 WebGL 或大体积动效库。
- 痛点与必要性来自原方案，仍明确标注待验证；不编造访谈、增长率或平台合作。

## 验收范围

- 保留同一静态站点、45 SKU、15 初始笔记、20 张图和原有路由。
- 使用现有 12 项回归检查；继续验证首屏 CTA、痛点导航、两端跳转、动效开关和手机溢出。
