# 双 App 视觉约定

## 展示看板：高饱和 editorial / pop

本轮用户明确要求大胆鲜明，而不只是 App 内部有颜色。外层使用葡萄紫主视觉、青绿/珊瑚橙/亮黄路径入口、宝蓝/薄荷绿/橙色实时机制卡，配深色轮廓与短硬阴影；保留暖白点阵底，阅读与图片区不染色。顶部增加独立品牌栏，手机保留可折叠指南。

参考 [Gumroad](https://gumroad.com/) 的大字号、明确轮廓、亮色装饰和卡片主次，及 [Figma](https://www.figma.com/) 的色块组合方向。不复制品牌资产，不增加纯装饰的大图下载。

保留原有跨端关联、购物车及安全门禁；本轮为展示层调整，不声称指标提升。

- 外围画布：温暖近白色，少量淡珊瑚/紫色光晕；不再把全站染成黄棕色。
- 内容社区：白底、莓果红品牌色、高清 AI 写实图、圆角轻卡片；不把生成图称为真实实拍。
- 外卖：亮蓝顶区、白色菜单卡、紫色推荐卡＋柠檬黄行动标签、彩色分类框、像素食物画与短硬阴影。正文用深蓝灰，不使用低分辨率字体。
- 颜色按角色分配：社区红、交易蓝、关联紫、购物车绿、模拟边界黄；正文与辅助说明均保留深色，避免低对比黄棕文字。
- 参考 [Headspace](https://www.headspace.com/) 的近白底与独立彩色模块、[Wolt](https://wolt.com/) 的鲜明蓝色品牌区、[Duolingo 设计说明](https://blog.duolingo.com/shape-language-duolingos-art-style/) 的鲜明颜色与白底控件层次。只借鉴组织方式，不复制品牌或界面。
- 同一道菜保持同一实体，两个端展示对应的不同风格素材。不是换图就换成别的菜。
- 像素画视觉颗粒目标约128–160格/边：可看出像素簇，仍保留菜品形态；不是照片模糊滤镜。
- 参考： [Maygetsu Cozy Thai Food](https://maygetsu.itch.io/cozy-thai-food-pixel-pack-free-sample) 的食物配色与像素簇；[Kenney Pixel UI Pack](https://kenney.nl/assets/pixel-ui-pack) 的控件层次。只借鉴设计原则，不复制素材或品牌。
